In example 2
for (int j=0; j < n; j += 2)

This loop increases by 2 each time, so it runs about n/2 times.

And because each iteration does constant-time operation which is (total += arr[j]), 
the running time is represented O(n).

In example 3
for (int j=0; j < n; j++)
    for (int k=0; k <= j; k++)

The loop in the outer part will run n amount of times.

The inner loop will run:

1 time when j = 0
2 times when j = 1
3 times when j = 2
...
n times when j = n - 1

This can be looked at in the expression:
1 + 2 + 3 + ... + n

If we use the arithmetic formula:
n(n+1)/2

This simplifies to O(n^2)

The best case running time is when the array is sorted in ascending order

Example:
[1,2,3,4,5]

What happens is for each iteration of the loop which is: 
while (j >= 0 && arr[j] > key)

the condition arr[j] > key is immediately false because every element is already in the correct position

So the while loop will execute 0 times for each pass and only 1 comparison is made for each iteration.

The outer loop will run n - 1 times, so it will grow linearly with n 

The worst case running time is when the array is sorted in descending order

Each element (which is key) is compared with all previously sorted elements and shifted to the
beginning of the array

Example:
2nd element compares once
3rd element compared twice
4th element compares 3 times
...
nth element compares n-1 times

This operation can be expressed by 1+2+3+...+(n-1)

This turns into the equation:  
n(n-1)/2

Which grows to:
O(n^2) 

In short: 
Best case is O(n) where the array is already sorted
Worst case is O(n^2) where the array is in reverse order
